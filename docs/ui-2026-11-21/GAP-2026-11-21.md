## ZuTalk core vs. the redesign: what the code backs today

Paths are relative to `/Users/kant/Zuzalu/zutalk`. One big finding: a person with only granted quota cannot get a whole-session transcript, because the server issues Soniox keys that only work for live streaming (B7). A second: nothing reports viewer counts, even though the server sends them on every write (I16).

### Facts that contradict docs/DESIGN.md
- §5.8 says the UI offers four options (always, 30, 7, 0); `Settings.svelte:9` has only three (no 30).
- §7.3 says how to show or copy the rotation key is still open; `Command::CopyRotation` already exists (`app.rs:367-373`) and the UI has a copy button (`Settings.svelte:38`).
- §5.9 says the whole-session job uses the glossary as it was when the recording started. A job retried at sign-in builds a new task with the current glossary (`app.rs:436-440,676`).
